# MI-CDM Data Spec Profiling

모델을 하나라도 불러오기 전에 "이 데이터셋에 실제로 무엇이 들어 있는가"에 답한다.

## 두 개의 패널

**패널 A — 획득 메타데이터.** MI-CDM에서 나온 샘플링 주파수, 리드 세트, 제조사, 노출 조건 등.

이걸 먼저 보는 이유: 획득 파라미터는 인구통계학적 요인만큼, 때로는 그 이상으로 모델 성능을 좌우한다. 그런데 대부분의 검증 연구는 이걸 보고하지 않는다 — 대개 쿼리할 방법이 없었기 때문이다. MI-CDM이 그걸 가능하게 만든 유일한 이유가 이 패널이므로, 여기서 지나치면 CDM을 쓴 의미가 없다.

**패널 B — 임상 특성.** index date 기준, *영상을 실제로 보유한* 환자들의 인구학·동반질환·검사값.

영상 보유 subset은 ATLAS 코호트가 아니다. 두 집단을 나란히 보고하면 selection bias가 암묵이 아니라 findings가 된다.

## 실행

```bash
mival profile -c configs/study.yaml     # → _workspace/02_data_spec.html
```

```python
from mival.profile.profiler import DataSpecProfiler
report = DataSpecProfiler(retrieval_result, characteristics_rows).profile()
DataSpecProfiler(retrieval_result).to_html(report)
```

패널 B는 `retrieve/sql/cohort_characteristics.sql` 결과가 필요하다. 없으면 `available: false`로 명시된다 — 없는 것을 없다고 적는 것과 조용히 빼는 것은 다르다.

## 요약 규칙

수치형과 범주형을 섞지 않는다. 500Hz와 1000Hz가 섞인 컬럼을 "평균 743Hz"로 보고하면 문제가 사라진다. 고유값이 적은 수치형은 통계량과 값 테이블을 **둘 다** 낸다.

리스트형 값(리드 이름 배열 등)은 튜플로 묶어 하나의 범주로 센다. 그래야 "12-lead 표준 순서"와 "순서가 다른 12-lead"가 서로 다른 값으로 보인다.

## 이질성 플래그

플래그는 실패가 아니라 **다음 행동의 제안**이다. 각각 왜 걸렸는지와 그래서 무엇을 할지를 함께 낸다.

| 플래그 | 조건 | 행동 |
|--------|------|------|
| `high_missingness` | 결측률 > 5% | 명시적으로 대치하거나 제외. 기본값으로 흘러가게 두지 않는다 |
| `multi_valued_acquisition` | 범주형 고유값 2~20개 | 5단계 층화 변수 후보 |
| `discrete_numeric_mix` | 이산 수치형에 값이 2개 이상 | 레시피에서 조화(예: resample)하고 그 사실을 기록하거나, 층화한다 |

## 층화 변수 추천 — 이 스킬의 실질적 산출물

리포트는 사람이 보고, 추천 목록은 파이프라인이 쓴다. `EvaluationSpec.subgroup_by`로 그대로 들어간다.

선정 기준:
1. 획득 메타데이터를 인구통계보다 **먼저** 넣는다.
2. 가장 작은 레벨의 n이 30 미만이면 후보에서 뺀다 (또는 레벨을 병합한다).
3. 결측률 50% 초과면 뺀다.
4. 총 5개를 넘기지 않는다. 층화 변수가 많으면 셀당 n이 무의미해지고, 그건 오히려 잘못된 확신을 만든다.

뺀 변수도 리포트에는 남기고 왜 뺐는지 적는다.

## 리포트 설계 원칙

병원 분석 워크스테이션에서 CDN을 못 부르는 경우가 흔하다. CSS는 인라인, 스크립트 없음, 막대는 CSS로 그린다. 외부 요청이 하나라도 있으면 리포트가 아니라 빈 페이지가 된다.

원본 JSON은 `<details>` 안에 통째로 넣는다. 요약을 못 믿는 사람이 원본을 볼 수 있어야 한다.

## 자주 겪는 문제

| 증상 | 원인 | 대응 |
|------|------|------|
| 패널 A가 비어 있음 | 1단계에서 메타데이터를 못 가져옴 | 조인 경로 확인 후 1단계 재실행. 빈 패널로 진행하면 층화 분석이 통째로 불가능해진다 |
| 플래그가 20개 이상 | 메타데이터 컬럼이 많은 정상 상황 | 상위 몇 개만 층화 후보로 좁히고 전수는 JSON에 남긴다 |
| 커버리지가 50% 미만 | 윈도우가 좁거나 modality 값 불일치 | 1단계로 회신. 진행은 가능하지만 일반화 주장의 범위가 좁아진다 |

## 재실행
